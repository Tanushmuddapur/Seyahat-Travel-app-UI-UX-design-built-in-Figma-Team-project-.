# Seyahat-Travel-app-UI-UX-design-built-in-Figma-Team-project-.

**Seyahat** is a modern travel app UI/UX design concept created in Figma by a team of 4 members. The design focuses on clean, user-friendly screens that help users explore destinations, plan trips, save favorites, and navigate travel options with ease.

## 🔗 Figma Design
👉 **View the design in Figma:** https://www.figma.com/design/3jUW1h82QzfKp0AL8Rxk3f/Untitled?node-id=1-17

## ✨ Highlights
- Designed for mobile travel experiences
- Clean and intuitive user interface
- Screens for destination browsing, trip planning, and favorites
- Prototype navigation to demonstrate flow and interactions

## 📌 Features
- Explore popular destinations  
- Trip planning UI  
- Save / favorite places  
- Profile & settings screens  
- Graphical consistency and smooth UX flow

## 🛠 Tools Used
- **Figma** – for UI design and prototyping
