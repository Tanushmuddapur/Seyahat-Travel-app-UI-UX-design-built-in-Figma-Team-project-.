# Seyahat-Travel-app-UI-UX-design-built-in-Figma-Team-project-.
Seyahat is a modern travel app UI/UX design made in Figma by a team of 4. It helps users explore destinations, plan trips, save favorites, and navigate smoothly through clean and user-friendly screens. The project highlights strong UI design, UX flow, and prototyping skills.
